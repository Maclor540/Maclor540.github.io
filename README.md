# Portafolio Profesional de Edición y Servicios Digitales

[![Estado](https://img.shields.io/badge/Estado-Activo-success.svg)]()
[![Tecnologías](https://img.shields.io/badge/Tecnolog%C3%ADas-HTML5%20%7C%20CSS3-blue.svg)]()

Este repositorio contiene el código fuente de mi portafolio profesional web. La página está diseñada para exhibir mis proyectos, servicios de edición de video (Maclor Freelance Services), postproducción y diseño, ofreciendo una interfaz limpia, responsiva y orientada a mostrar resultados.

## 🌐 Demo en vivo
Puedes visualizar el portafolio operativo aquí: **[https://maclor540.github.io](https://maclor540.github.io)** *(Nota: Si cambias tu nombre de usuario de GitHub a tu nombre real, asegúrate de actualizar este enlace y el nombre del repositorio).*

## 🚀 Características
*   **Diseño Responsivo:** Adaptable fluidamente a dispositivos móviles, tablets y monitores de escritorio.
*   **Maquetación Semántica:** Código HTML5 estructurado para mejorar el rendimiento, la accesibilidad y el SEO.
*   **Estilos Personalizados:** Diseño visual construido enteramente con CSS3 puro (animaciones, transiciones, layouts adaptativos) garantizando tiempos de carga rápidos sin depender de frameworks externos.
*   **Exhibición de Servicios:** Secciones estructuradas para detallar trabajos de edición avanzada (DaVinci Resolve, Premiere Pro), motion graphics y diseño.

## 🛠️ Tecnologías Utilizadas
*   **Frontend:** HTML5, CSS3.
*   **Despliegue y Hosting:** GitHub Pages.
